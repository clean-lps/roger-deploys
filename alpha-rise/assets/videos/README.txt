Gallery video — Alpha Rise
==========================

Drop the project video here. The gallery section updates automatically the next
time you run the build (the manifest is regenerated by
scripts/generate-gallery-manifest.js before every `pnpm dev` or `pnpm build`).

Naming:
  gallery-video.mp4           <- the video itself
  gallery-video-poster.jpg    <- optional still frame shown before playback

Rules:
  - Formats: .mp4, .webm, .ogg
  - Only one video is used; the first file in natural order wins
  - Keep the poster next to the video using the same base name + "-poster"
    (it is what visitors see in the gallery grid, so the tile is never blank)
  - If the video should NOT appear on the site, remove it from this folder

Regenerating the poster frame from the video (optional, requires ffmpeg):
  ffmpeg -y -ss 1 -i gallery-video.mp4 -frames:v 1 -q:v 3 gallery-video-poster.jpg
