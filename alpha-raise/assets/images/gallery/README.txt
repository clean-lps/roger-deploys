Gallery photos — Alpha Rise
=============================

Drop completed-work photos here. The gallery section updates automatically
the next time you run the build (the manifest is regenerated by
scripts/generate-gallery-manifest.js before every `pnpm dev` or `pnpm build`).

Naming:
  gallery-01.jpg
  gallery-02.jpg
  gallery-03.jpg
  ...

Rules:
  - Formats: .jpg, .jpeg, .png, .webp
  - Numbering is sequential; keep leading zeros (gallery-02.jpg, not gallery-2.jpg)
  - Mixed portrait / landscape photos are supported (masonry layout)
  - Anything in this folder is displayed on the site as a finished project

If a photo should NOT appear on the site, remove it from this folder.
